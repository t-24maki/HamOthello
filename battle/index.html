ボタンとキーボードのあそび方

左右 / A・D：移動　↑ / W / Space：ジャンプ（空中でもう1回）
Z / J：こうげき　X / K：ひっさつ　C / L：ガード（長押し）
Esc / P：ひとやすみ

「ひっさつ」は上に飛びながら回転する技。空中では着地まで1回だけ。ガードは地上で使え、長く守るとゲージがなくなって少し動けなくなるよ。「ひだまりひろば」は坂道、「わたぐもテラス」は動く床にも注目。画面を離れると自動で一時停止し、BGMも止まります。

たくハムはすばやく近づいて、こつこつ攻撃。めぐハムは高いジャンプと強い一撃で勝負。「ひっさつ」も、たくハムは横へ、めぐハムは上へ進みやすいよ。色違いでも強さは同じです。

通信対戦は、同じキーワードでふたりをつなぐよ。ふたりの準備が揃うと開始。画面を離れたり、通信が遅くなると一時停止します。再戦もふたりが選ぶと始まるよ。
左右ボタンは、押したまま指をすべらせて切り替えられるよ。移動しながらジャンプや攻撃もできるよ。
